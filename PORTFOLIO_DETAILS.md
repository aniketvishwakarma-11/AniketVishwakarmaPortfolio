## 🚀 How to Rebuild This Portfolio from Scratch

### 1. Project Setup
```bash
# Create new Next.js project with TypeScript
npx create-next-app@latest aniketvishwakarmaportfolio --typescript --tailwind --eslint

# Install additional dependencies
npm install framer-motion lucide-react react-type-animation
```

### 2. Configure TypeScript & Tools
- Use provided `tsconfig.json` configuration
- Set up ESLint with `eslint.config.mjs`
- Configure Tailwind with `tailwind.config.mjs`
- Configure PostCSS with `postcss.config.mjs`

### 3. Create Component Structure
- `components/Navigation.tsx` - Sticky navbar with menu
- `components/About.tsx` - Hero/about section with stats
- `components/Experience.tsx` - Timeline component
- `components/ProjectCard.tsx` - Reusable project card
- `components/Footer.tsx` - Footer with social links

### 4. Create Data Layer
- `lib/project.ts` - Array of 6 projects with metadata

### 5. Create Main Page
- `app/page.tsx` - Main entry point with all components
- `app/layout.tsx` - Root layout
- `app/globals.css` - Global styles

### 6. Add Animations
- Framer Motion for component animations
- TypeAnimation for hero text effects
- Scroll-triggered animations with `whileInView`

### 7. Styling
- Tailwind CSS for utility-first styling
- Custom gradients for branding
- Dark theme with cyan/blue accents
- Responsive breakpoints (sm, md, lg)

### 8. Deployment
- Deploy to Vercel for Next.js hosting
- Use environment variables for sensitive data
- Configure deployment settings in `next.config.ts`
